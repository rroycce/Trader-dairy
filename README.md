# Trader Diary

A web application for recording and analyzing trading executions.

## Features
- Secure user authentication
- Trade logging (Pair, Direction, Entry/Exit prices, Notes)
- Auto-calculation of trade results (Win/Loss/Breakeven)
- Isolated user data using Row Level Security (RLS)

## Tech Stack
- **Frontend:** HTML, CSS, Vanilla JavaScript
- **Backend & Database:** Supabase (PostgreSQL, Auth)
- **Hosting:** Vercel
